개인정보 처리방침

시행일: 2026-11-16

1. 무엇을 하나요

JREPLACE 메일 도우미(이하 "도구")는 JREPLACE 가 자기 Gmail 계정의 메일을 읽어 주문·배송 기록을 정리하는 개인용 도구입니다.

2. 어떤 정보를 쓰나요

사용자가 Google 로그인으로 허락한 경우에만 Gmail API 읽기 전용 권한(https://www.googleapis.com/auth/gmail.readonly)으로 메일의 제목·발신자·날짜·본문을 읽습니다. 메일을 보내거나 지우거나 바꾸지 않습니다.

3. 어디에 저장하나요

읽은 내용과 인증 토큰은 사용자 본인의 컴퓨터에만 저장합니다(토큰은 운영체제 키체인). 외부 서버로 보내거나 제3자에게 제공·판매하지 않습니다.

4. Google API 데이터 사용

도구가 Google API 에서 받은 정보의 사용과 이전은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 보관과 삭제

사용자는 언제든 Google 계정 권한 페이지에서 접근 권한을 철회할 수 있으며, 철회하면 도구는 더 이상 메일을 읽지 못합니다. 로컬에 저장된 기록은 사용자가 직접 지울 수 있습니다.
